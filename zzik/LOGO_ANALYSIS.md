## 🔍 변형별 상세 분석

### Variant 1: 왼쪽 상단 (Dark 3D Embossed)

#### 시각적 특징
- **배경**: 짙은 다크 그레이 (약 `#2C3E4F`)
- **스타일**: 3D 엠보스 효과, 깊은 그림자
- **Play 아이콘**: 민트/틸 그린 (음영 있음)
- **Location Pin**: 다크 그레이, 볼륨감 있는 입체 표현
- **테두리**: 없음 (그림자로 경계 표현)

#### 기술적 평가
- **대비**: 낮음 (다크 온 다크)
- **접근성**: ⚠️ 낮은 대비로 가독성 떨어짐
- **3D 효과**: 매우 강함 (Inner shadow + Drop shadow)
- **스케일**: 작은 크기에서 디테일 손실 가능

#### 적합한 사용처
- ✅ 다크 모드 히어로 섹션 (대형 사이즈)
- ✅ 프리미엄 브랜드 이미지
- ❌ Favicon (너무 복잡)
- ❌ 모바일 앱 아이콘 (디테일 과다)

#### Linear 2025 부합도: ⭐⭐☆☆☆ (2/5)
- **이유**: Linear는 플랫/미니멀 지향, 3D 효과 과다

---

### Variant 2: 오른쪽 상단 (Light Flat Minimal)

#### 시각적 특징
- **배경**: 순백 또는 아이보리 (`#F8F8F8`)
- **스타일**: 완전 플랫, 그림자 없음
- **Play 아이콘**: 틸 그린 (단색)
- **Location Pin**: 다크 그레이 (단색, 플랫)
- **테두리**: 미묘한 라운드 (rounded-corners)

#### 기술적 평가
- **대비**: 높음 (다크 아이콘 on 라이트 배경)
- **접근성**: ✅ WCAG AA 이상
- **스타일**: 미니멀, 현대적
- **스케일**: 모든 크기에서 선명함

#### 적합한 사용처
- ✅ Favicon (16x16px에서도 선명)
- ✅ 라이트 모드 UI
- ✅ 인쇄물 (명함, 브로셔)
- ⚠️ 다크 모드 (배경 전환 필요)

#### Linear 2025 부합도: ⭐⭐⭐⭐☆ (4/5)
- **이유**: 미니멀, 깔끔, 스케일 우수

---

### Variant 3: 왼쪽 하단 (Light High-Contrast)

#### 시각적 특징
- **배경**: 밝은 베이지/크림 (`#E8E4DC`)
- **스타일**: 하이 컨트라스트, 볼드
- **Play 아이콘**: 틸 그린 (약간 그라디언트)
- **Location Pin**: 완전한 검정 (`#000` 또는 매우 어두운 회색)
- **테두리**: 미묘한 경계선
- **하단 디테일**: 작은 대시 (강조 포인트)

#### 기술적 평가
- **대비**: 매우 높음 (검정 on 라이트)
- **접근성**: ✅ WCAG AAA 수준
- **가독성**: 최상
- **스케일**: 중간 크기 이상 권장

#### 적합한 사용처
- ✅ 히어로 섹션 (라이트 모드)
- ✅ 마케팅 자료
- ✅ 소셜 미디어 프로필
- ❌ 다크 모드 (배경 반전 필요)

#### Linear 2025 부합도: ⭐⭐⭐☆☆ (3/5)
- **이유**: 깔끔하지만 다크 모드 기본인 Linear와 방향 불일치

---

### Variant 4: 오른쪽 하단 (Light Soft Shadow)

#### 시각적 특징
- **배경**: 순백 (`#FFFFFF`)
- **스타일**: 소프트 드롭 섀도우, 모던
- **Play 아이콘**: 틸 그린 (미세 그라디언트)
- **Location Pin**: 다크 그레이 (약간 그라디언트)
- **테두리**: Subtle border
- **그림자**: 부드러운 외곽 섀도우 (blur 10-15px)

#### 기술적 평가
- **대비**: 높음 (섀도우로 입체감)
- **접근성**: ✅ WCAG AA
- **3D 효과**: 미묘 (과하지 않음)
- **스케일**: 중~대형 크기 최적

#### 적합한 사용처
- ✅ 앱 아이콘 (iOS/Android)
- ✅ 랜딩 페이지 히어로
- ✅ 라이트 모드 네비게이션
- ⚠️ Favicon (섀도우 디테일 손실)

#### Linear 2025 부합도: ⭐⭐⭐⭐⭐ (5/5)
- **이유**: 
  - 부드러운 섀도우 = Linear의 "subtle elevation"
  - 깔끔한 아이콘 = 미니멀리즘
  - 틸 그린 = 브랜드 컬러 강조
  - 스케일 우수

--logo-bg-dark: oklch(15% 0.02 240);

## 🚀 즉시 적용 가능한 코드

### Next.js 컴포넌트
```tsx
// components/Logo.tsx
export function Logo({ variant = 'default', size = 32 }) {
  const isDark = true; // 또는 useTheme()
  
  if (size <= 32) {
    // Favicon: Variant 2 (플랫)
    return <LogoFlat size={size} />;
  }
  
  // 일반: Variant 4 (소프트 섀도우)
  return <LogoSoft size={size} dark={isDark} />;
}
```

### 헤더에 적용
```tsx
// page.tsx
<div className="flex items-center gap-3">
  <Logo size={32} />
  <span className="text-sm font-semibold">ZZIK</span>
</div>
```
